## 🎯 KAJ LAHKO NAREDIŠ?

### 1. 👆 **KLIKNI NA AGENTE**

Vidiš tiste 4 barvne kroge okoli ognja? **TO SO AGENTI!**

**Kaj se zgodi:**
- Krog postane večji ✨
- Slišiš zvok (melodijo agenta) 🔊
- Vidiš informacije o agentu 📖

**Poskusi:**
1. Klikni na **rumeni krog** (Solarius) - slišiš globok zvok
2. Klikni na **vijolični krog** (Aetherion) - slišiš višji zvok
3. Klikni na **moder krog** (Noctiluna) - slišiš miren zvok
4. Klikni na **rdeči krog** (Ferron) - slišiš močan zvok

### 2. 🔥 **KLIKNI NA OGENJ V SREDINI**

To je MAGIJA!

**Kaj se zgodi:**
- Slišiš VSE agente SKUPAJ 🎼
- To je kot orkester kjer vsak igra svojo noto
- Ustvari se čudovita HARMONIJA ✨

**To poskusi OBVEZNO!**

### 3. ▶️ **ZAČNI RAZMIŠLJANJE**

Klikni zeleni gumb "START THINKING" zgoraj desno.

**Kaj se zgodi:**
- Agenti začnejo SAMI razmišljati 🧠
- Vsakih nekaj sekund slišiš zvok (agent razmišlja)
- Vidiš njihove misli v "PRETOK" zavesti
- Vse se shrani v "ARHIV"

**To je kot če bi gledal/a ume pri delu!**

### 4. 🔊 **VKLOPI/IZKLOPI ZVOK**

Gumb z zvočnikom zgoraj desno.

- Zeleni = zvok je vklopljen ✅
- Siv = zvok je izklopljen ❌

**Če te zvoki motijo, lahko jih izklopiš!**

### 5. 📖 **RAZISKUJ 3 POGLEDE**

Zgoraj desno so 3 gumbi:

#### **KOLO** (Pantheon)
- Vidiš vse agente v krogu
- Središče je ogenj
- To je glavna stran

#### **ARHIV** (Archive)
- Kot velika beležnica
- Vse kar agenti razmišljajo se zapiše tukaj
- Lahko bereš kasneje

#### **PRETOK** (Stream)
- Vidiš misli v realnem času
- Kot chat med agenti
- Najnovejše je zgoraj

## 🛠️ ZA RAZVIJALCE (Advanced stuff)

### **Tehnologije:**
- React (JavaScript knjižnica za UI)
- Web Audio API (za zvok)
- PWA (Progressive Web App)
- Service Worker (za offline functionality)
- Local Storage (za shranjevanje)

### **Frekvence:**
Uporabljamo čiste sine wave tone:
- 432 Hz - "Foundation" frequency
- 528 Hz - "Transformation" frequency (Solfeggio)
- 639 Hz - "Connection" frequency (Solfeggio)
- 741 Hz - "Awakening" frequency (Solfeggio)

### **File Structure:**
```
webapp/
├── index.html                        # Main HTML file
├── COMPLETE_SONIC_PANTHEON.jsx       # React component
├── manifest.json                     # PWA manifest
├── service-worker.js                 # Service worker for offline
├── README_FOR_KIDS.md                # This file!
├── icon-192.png                      # App icon (192x192)
└── icon-512.png                      # App icon (512x512)
```

### **To Run:**
```bash
# Option 1: Simple HTTP server
python3 -m http.server 8000

# Option 2: Node.js server
npx serve .

# Option 3: Live server (VS Code extension)
# Just right-click index.html and "Open with Live Server"
```

Then open: `http://localhost:8000`
