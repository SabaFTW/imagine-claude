## 💡 TIPS & TRICKS

### **Za boljši performance:**

```jsx
// Use React.memo for heavy components
const FleetWidget = React.memo(() => {
  // component code
});
```

### **Za PWA instalacijo:**

1. Dodaj `manifest.json` v `public/`
2. Dodaj ikone v `public/`
3. Edit `index.html`:

```html
<link rel="manifest" href="/manifest.json" />
<link rel="icon" href="/icon-192.png" />
```

### **Za offline:**

```jsx
// V index.js ali main.jsx:
if ('serviceWorker' in navigator) {
  navigator.serviceWorker.register('/service-worker.js');
}
```

## 🐛 TROUBLESHOOTING

### **"recharts not found"**
```bash
npm install recharts
```

### **"lucide-react not found"**
```bash
npm install lucide-react
```

### **"Audio doesn't play"**
- Klikni KAMORKOLI na stran prvo (browser autoplay policy)
- Check if audio toggle is ON (green)
- Try in different browser

### **"Manifest not loading"**
- Check `public/manifest.json` exists
- Check `index.html` has link to manifest
- Hard refresh (Ctrl+Shift+R)
