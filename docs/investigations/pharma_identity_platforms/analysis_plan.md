# Analysis Plan

## 1) Collection
- Fetch primary docs (DSM-5, ICD-11, WPATH SOC-8), high-quality reviews (Cass, meta-analyses), class revenue data, lobbying registries, platform policy docs, curricula.

## 2) Extraction
- For each claim: extract exact quotes, figures, time windows, effect sizes, follow-up durations, attrition rates, definitions used (e.g., "detransition").

## 3) Grading
- Apply A–D rubric per claim and per source.
- Note heterogeneity, confounders, measurement bias, selection effects.

## 4) Synthesis
- Build a traffic-light matrix (green = stronger, amber = mixed/uncertain, red = weak).
- Separate **what we know** vs **what we don't know**.

## 5) Reporting
- Write plain-language summaries with footnotes to primary sources.
- Distinguish: **documented** / **contested** / **unknown**.
- Include an ethics section emphasizing dignity, consent, and non-stigmatization.

## 6) Release Plan
- v0.2: Insert verified quotes and figures.
- v0.3: Add matrix + graphs.
- v1.0: Publish balanced report with transparency notes and data appendix.
