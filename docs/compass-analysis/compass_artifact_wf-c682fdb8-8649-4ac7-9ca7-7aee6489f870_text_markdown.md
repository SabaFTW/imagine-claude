3. **Homomorphic Encryption**: Computation on encrypted data without decryption. Enables biometric verification without storing biometrics. Limitation: 1000x+ slower than plaintext.

- **1 in 50 billion false positive rate**
- Used by 200+ platforms globally
- **2024 Impact**: 112.3B images/videos processed, 4.2M suspected CSAM flagged
- **Success**: UK-hosted CSAM reduced 18% (1996) → 0.04% (2024)

**Technical Properties**:
- Surgical precision: targets specific illegal content without blanket scanning
- Privacy-preserving: only matches known hashes, doesn't monitor other communications
- Non-invasive: scans server-side on platforms, not user devices

- Human expertise + technology amplification
- Anonymous reporting from 52 countries

- Project Artemis (Microsoft/UK Home Office) claims 88% accuracy
