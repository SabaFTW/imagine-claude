Frequently Asked Questions

                
Everything you need to know about FORGE

            

            

                

                    

                        How does FORGE handle my proprietary designs and IP?
                        
                    

                    

                        
FORGE operates on a strict local-first principle. Your files never leave your infrastructure unless you explicitly enable cloud sync. All processing happens on your hardware, and we use end-to-end encryption for any optional cloud services.

                    

                

                

                    

                        What file formats does FORGE support?
                        
                    

                    

                        
FORGE supports all major CAD and 3D file formats including STEP, STL, OBJ, IGES, SLDPRT, DWG, DXF, FBX, and more. We're constantly adding support for new formats based on user demand.

                    

                

                

                    

                        Can I use FORGE with my existing workflow tools?
                        
                    

                    

                        
Absolutely. FORGE integrates seamlessly with popular tools like SolidWorks, Fusion 360, Blender, and major slicers. Our API also allows custom integrations with proprietary or niche tools.

                    

                

                

                    

                        What are the system requirements?
                        
                    

                    

                        
FORGE runs on Windows, macOS, and Linux. Minimum requirements: 8GB RAM, 4-core CPU, dedicated GPU recommended for advanced features. The application is optimized to run efficiently even on older hardware.
