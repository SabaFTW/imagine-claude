## 🔧 TROUBLESHOOTING:

### Problem: "npm: command not found"
**Fix:** Instaliraj Node.js:
```bash
sudo apt install nodejs npm
```

### Problem: Tailwind ne dela
**Fix:** Že vključen preko CDN v index.html — should work!

### Problem: Font ne izgleda prav
**Fix:** Google Fonts Cinzel je že vključen — refresh browser!
