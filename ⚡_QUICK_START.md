# ⚡ QUICK START GUIDE ⚡

**For when you want to run the Command Center!**

---

## 🚀 START SERVER

```bash
cd /home/saba/Desktop/Saba_Place/creative-lab/
npm run dev -- --host
```

**Will show:**
```
✅ Local:   http://localhost:3000/
✅ Network: http://YOUR-IP:3000/
```

---

## 💻 DESKTOP ACCESS

Open browser:
```
http://localhost:3000/
```

**You'll see:**
- 🔥 Flame particles dancing
- 🜂 Giant breathing flame
- 🎴 12 sphere cards

**Click any sphere to explore!**

---

## 📱 PHONE ACCESS (Same WiFi!)

**1. Find your IP:**
```bash
ip addr show | grep "inet " | grep -v 127.0.0.1
```

**2. On phone (Safari/Chrome):**
```
http://YOUR-IP:3000/
```

**3. Install as PWA:**
- Safari: Share → Add to Home Screen
- Chrome: Menu → Install app

## 💡 TIPS

**Development:**
- Changes auto-reload (HMR)!
- Check console for errors (F12)
- Mobile: Use actual phone (better than emulator)

**Mobile Testing:**
- Must be same WiFi
- IP might change (check each time)
- Safari best for iOS PWA

**Building:**
```bash
npm run build     # Production build
npm run preview   # Test production
```
